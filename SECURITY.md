# Security policy

## What this project handles

`y2diag` reads **local git history** (author e-mails are used only to map to teams and are never written to reports). It makes no network calls. The tracing demo binds to `127.0.0.1` only.

## Please do not

- Commit secrets, tokens, real customer data, real subscription/tenant IDs, or real author data to this repo or its issues.
- Publish reports from private repositories without reviewing them.

## Reporting a vulnerability

Open a private security advisory on the repository (Security tab > Report a vulnerability). If unavailable, open an issue **without exploit details** asking for a private channel. Expect an acknowledgement within a week.

## Supported versions

Latest release only.
